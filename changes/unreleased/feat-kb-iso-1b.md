- **Knowledge Bases:** A source's first pass stops at 10,000 items when it holds more, for a connector's first sync and a Workflow's first `ingest` alike. It takes in the first 10,000, lists the rest, and waits as "Waiting for confirmation" / "Wartet auf Bestätigung" in "Sources" / "Quellen" with the count, the size and an estimate as ranges: passages, tokens, the embedding cost priced from the rate card ("12,000 files, 318 GB, estimated embedding cost €250.00 to €380.00" / "12.000 Dateien, 318 GB, geschätzte Kosten der Einbettung 250,00 € bis 380,00 €"), and whether the store has room. Every reader of the page sees the state; only a holder of `knowledge_base.publish` gets "Continue import" / "Import fortsetzen". `knowledge_bases.sync` takes `confirm: true` and the CLI `catalyst knowledge-base sync <kb> --source <id> --confirm`; the confirmation is audited as `knowledge_base.first_pass_confirmed` with counts and the estimate, never a name. `knowledge_bases.sources` carries the estimate as `confirmation` while a source waits. A Workflow's waiting `ingest` step keeps waiting; a confirmation after its run ended lets the pass go on, which then withdraws nothing. A later pass, and a source of up to 10,000 items, never waits. No migration: the stop is kept on the sync run's progress.
