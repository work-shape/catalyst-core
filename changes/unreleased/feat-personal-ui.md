Personal connections in the interface. Settings > You > Connections lists each personal Connection a person may use with their own account's state, since when it is connected and the last day it was used; One click on Connect opens the provider in a small window (a new tab where the browser opens none), whose own page shows the permissions; Disconnect asks once. A personal Connection's page connects the reader's own account in its Sign-in section and shows holders of `connection.write` a People section with Revoke, which says that the grant at the provider stays. The New connection dialog asks "Whose account" (Shared or Personal, Shared by default) for an MCP server and a REST API that signs a person in; the Connection page shows the choice locked. An agent's tools carry a "Personal" chip on a personal Connection. `connections.list_tools` marks a personal Connection with `personal: true`, and `connections.people` names each person by the display label the list of users shows.
