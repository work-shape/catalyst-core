section: Added
---

Connection catalogue OAuth endpoints can bind named path segments, so a tenant field can
configure authorization and token URLs together without changing their hosts. Catalogue setup
checklists can show the current instance’s redirect URI. Declared HTTP query parameters support
fixed `const` values hidden from tool input and defaults when omitted, allowing read-only mail
presets to fix response format and cap page sizes. The Gmail and Outlook entries and pure mail
result shapers live in the capabilities connection-catalogue package; no deployment enables them.
