- The Results tools on the agent page say what they do: **Keep a fact sheet** ("Faktenblatt führen"), **Read the fact sheet** ("Faktenblatt lesen") and **Reopen an earlier result** ("Früheres Ergebnis öffnen"). Keeping the fact sheet and reading it are one check box: on, the agent holds `structured_data.publish` and `structured_data.read`; off, neither. An agent stored with only `structured_data.publish` shows the box on and is saved with both. The tool names are unchanged.
