- **Connections:** A shared Connection that sends a bearer token or an API key header can hold a test credential for the outside system's test or sandbox account (ADR-0031). When it is set, the drafts of Apps and the test runs of Workflows call the Connection with it, reading and changing alike, and their Operation Runs record the target `test`; published Apps, live Workflow runs and agents never use it. It may carry its own address in the connector type's endpoint setting, which must be on the egress list. A holder of `connection.write` sets, rotates and removes it write-only: under **Test credential** on the Connection's page, with `catalyst connection secret set <name> --test [--endpoint <url>] [--account <name>]` and `catalyst connection secret remove <name> --test`, or through `connections.set_test_credential` and `connections.remove_test_credential`. The value is never answered, logged or audited; the audit events `connection.test_credential_set` and `connection.test_credential_removed` name the Connection, the version and the host of a test address. A draft's call never falls back to the live key: where the test credential no longer fits the Connection's address or auth scheme, the call is refused with `test_target_missing`, and the Connection's status is left as it is. The Actions list of an App's draft names the target `test` for an action whose Connection has one.
