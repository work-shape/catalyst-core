- **Scheduled prompts:** Scheduled prompts now save a prompt, an available agent and an IANA-zone schedule under Scheduled / Geplant. They run on the shared executor as their owner with current access and private result conversations. Owners can create, edit, run now, pause, resume and delete starts; instance admins can hand over or delete a deactivated owner's starts. Agent scheduling tools ask for confirmation. Unattended confirmations wait in the owner's Inbox and skip overlapping ticks.
