- Workshaper, the agent that ships with the platform (SA-1), behind the Module `workshaper` (off by default). The release seed creates it offered in no workspace and never changes where it is offered; where the instance names no default agent it is the default in the workspaces that offer it. Each release merges into the instance's changes field by field, tools and skills one by one; the agent page marks fields that differ from what shipped and resets them. Its name is reserved, it cannot be deleted, and `catalyst config pull` skips it.
